## Hackathons

| Project | Event | Result |

**Nudge** is an augmented reality app that scans the person in front of you and shows the interests you share, so a conversation can start on its own. Unity, C#, Microsoft Cognitive Services, Vuforia, with face tracking on Google Tango. [Demo video](https://www.youtube.com/watch?v=IQ9PetAPLa8).

**Flan** is an AR menu: build a dish ingredient by ingredient, skip allergens, and see a 3D model of what you'll get before you order. Unity, ARCore and photogrammetry.
